# Aunty Scanner

Aunty Scanner is a Flutter app that helps users **find nearby home-food providers (“Aunties”) in real time**.  
It is designed for people living away from home (students, working professionals, etc.) who want access to **fresh homemade food** in their area.

---

## 🌟 Overview

Many people who live far from their families struggle to find healthy, homemade meals every day.  
**Aunty Scanner** connects users with local home chefs (“Aunties”) who are registered on the app and available to serve food nearby.

The app focuses on:

- Real-time nearby provider discovery
- Easy connection between users and food providers
- Supporting local home-food services

---

## ✨ Features

- 📍 **Real-time nearby aunty discovery**
- 🧭 **Location-based matching**
- 🍱 **Homemade food provider listing**
- 📱 **Simple and user-friendly Flutter interface**
- 🤝 **Community-based food support for people living away from home**

## 📦 Getting Started

### Prerequisites

Make sure you have installed:

- [Flutter SDK (stable)](https://docs.flutter.dev/get-started/install)
- Android Studio or VS Code
- Android SDK / Xcode (for device builds)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Divyanshu8595/auntyScanner.git
cd auntyScanner
```

2. Install dependencies:

```bash
flutter pub get
```

3. Run the app:

```bash
flutter run
```

---

## 🚀 Build
